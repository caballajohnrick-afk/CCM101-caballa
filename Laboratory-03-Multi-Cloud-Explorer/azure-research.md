# Microsoft Azure

## Brief Overview

Microsoft Azure is a cloud platform created by Microsoft.

It allows people and companies to use online services for:
- Computing
- Data storage
- Networking
- Databases
- Security
- Artificial Intelligence (AI)
- Application development

With Azure, companies can use cloud resources without needing to manage all of their own physical servers.

## Global Infrastructure

Microsoft Azure has data centers in many parts of the world.

Azure uses **Regions** and **Availability Zones** to provide cloud services in different locations.

This helps users run applications closer to their customers and helps keep services available if a problem happens in one location.

## Cloud Management Console

The **Azure Portal** is a web-based tool for managing Azure services.

Users can use the portal to:
- Create cloud resources
- Configure services
- Monitor applications
- Manage virtual machines
- Check resource usage

## Four Core Services

### 1. Azure Virtual Machines

**Azure Virtual Machines (VMs)** are virtual computers that run in the cloud.

Users can install operating systems and run applications on these virtual computers.

### 2. Azure Blob Storage

**Azure Blob Storage** is a service for storing large amounts of data.

It can store:
- Documents
- Photos
- Videos
- Backup files
- Other types of data

### 3. Azure Virtual Network

**Azure Virtual Network** allows Azure resources to connect through a private network.

It helps users control network communication between virtual machines, applications, and other Azure services.

### 4. Microsoft Entra ID

**Microsoft Entra ID** is an identity and access management service.

It helps manage users and control access to Azure services and resources.

## Three Advantages

1. Azure works well with Microsoft products and services.
2. Azure has cloud infrastructure in many locations around the world.
3. Azure offers many services that can support different business needs.

## Typical Enterprise Use Cases

Companies can use Azure for:

- Running Windows-based applications
- Hosting business applications
- Storing company data
- Managing cloud databases
- Running virtual machines
- Supporting hybrid cloud environments
