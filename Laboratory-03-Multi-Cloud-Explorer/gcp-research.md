# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform (GCP) is a cloud service provided by Google.

It offers different services for:
- Computing
- Storage
- Networking
- Databases
- Artificial Intelligence (AI)
- Machine Learning
- Data analysis
- Application development

Companies can use GCP to build, run, and manage applications online.

## Global Infrastructure

Google Cloud has data centers located in different parts of the world.

Its infrastructure is divided into **Regions** and **Zones**.

A **Region** is a specific geographic area, while a **Zone** is a location inside a Region.

This allows companies to run their applications in different locations and provide better performance for users around the world.

## Cloud Management Console

The **Google Cloud Console** is a website used to manage Google Cloud services.

Users can use it to:
- Create cloud resources
- Configure services
- Monitor resources
- Manage applications
- Check cloud usage

## Four Core Services

### 1. Compute Engine

**Compute Engine** provides virtual machines that run on Google's cloud.

These virtual computers can be used to run websites, applications, and other programs.

### 2. Cloud Storage

**Cloud Storage** is an online storage service.

It allows users to save and access different types of data, such as:
- Files
- Images
- Videos
- Backups
- Application data

### 3. Google Virtual Private Cloud (VPC)

**Google Cloud VPC** provides a private network for cloud resources.

It allows virtual machines, containers, and other services to communicate with each other securely.

### 4. Google Kubernetes Engine (GKE)

**Google Kubernetes Engine (GKE)** is a service used to run and manage applications inside containers.

It uses Kubernetes to help deploy and manage containerized applications.

## Three Advantages

1. GCP provides powerful tools for Artificial Intelligence and Machine Learning.
2. GCP has strong services for storing, processing, and analyzing data.
3. GCP provides excellent support for Kubernetes and container-based applications.

## Typical Enterprise Use Cases

Companies can use GCP for:

- Artificial Intelligence and Machine Learning
- Big data and data analytics
- Hosting websites and applications
- Running containerized applications
- Managing Kubernetes applications
