# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is Amazon's cloud computing platform.

It provides cloud services such as:
- Computing
- Storage
- Networking
- Databases
- Security
- Application development

Companies can use AWS without having to own and maintain many physical computers and servers.

## Global Infrastructure

AWS has data centers in different parts of the world.

These are organized into **Regions** and **Availability Zones**.

A **Region** is a geographic area where AWS has data centers.

An **Availability Zone** is a separate location inside a Region.

This helps applications stay available and work properly even if one location has a problem.

## Cloud Management Console

The **AWS Management Console** is a website used to manage AWS services.

Users can use the console to:
- Create resources
- Set up resources
- Monitor resources
- Manage AWS services

## Four Core Services

### 1. Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual computers or servers.

Companies can use EC2 to run websites, applications, and other programs.

### 2. Amazon S3

**Amazon Simple Storage Service (S3)** is a cloud storage service.

It can be used to store:
- Files
- Images
- Backups
- Application data

### 3. Amazon VPC

**Amazon Virtual Private Cloud (VPC)** is a networking service.

It allows companies to create a private network for their AWS resources.

It also helps control how different resources connect to each other.

### 4. AWS IAM

**AWS Identity and Access Management (IAM)** is a security service.

It controls who can access AWS resources and what they are allowed to do.

IAM manages:
- Users
- Roles
- Permissions
- Policies

## Three Advantages

1. AWS provides many different cloud services for businesses.
2. AWS has data centers around the world, so applications can be used in different locations.
3. AWS can increase or decrease resources depending on the needs of the business.

## Typical Enterprise Use Cases

Companies commonly use AWS for:

- Hosting websites and web applications
- Storing and backing up data
- Running business applications
- Disaster recovery
- Processing and analyzing data
