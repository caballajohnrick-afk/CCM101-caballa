# Cloud Infrastructure Components

## Compute Resources
* **Function**: Tasks are executed and applications are run through the CPU and its cores[cite: 1].
* **Importance**: Cloud infrastructure inherently requires this processing power to operate effectively[cite: 1].
* **KillerCoda Context**: In the Ubuntu environment, executing the `lscpu` command displays your system's compute power[cite: 1].

---

## Storage Resources
* **Function**: Storage acts as the primary holder for files and data[cite: 1].
* **Importance**: This is vital for persisting databases and saving application files[cite: 1].
* **KillerCoda Context**: You can inspect available storage capacity in KillerCoda using the `df -h` command[cite: 1].

---

## Networking Resources
* **Function**: Systems connect and interface with one another using IP addresses[cite: 1].
* **Importance**: Reliable networking is essential for facilitating communication throughout the cloud[cite: 1].
* **KillerCoda Context**: Running `ip a` on KillerCoda Ubuntu reveals the IP details that represent networking capabilities[cite: 1].

---

## Operating System
* **Function**: Linux controls and allocates underlying hardware and software resources[cite: 1].
* **Importance**: Operating systems serve as the foundational layer that cloud servers depend on[cite: 1].
* **KillerCoda Context**: KillerCoda runs on Linux specifically using the Ubuntu distribution[cite: 1].
