# Mission Reflection

During this activity, I learned about key cloud components like compute, storage, networking, and operating systems. In my opinion, compute resources are the most important part because they process tasks and run software. Without CPU power, the system cannot function at all. It acts like the "brain" of the cloud, making it essential.

Linux helps cloud computing by offering a stable operating system to control hardware. It lets users run commands, manage files, and handle processes smoothly. Most cloud servers use Linux because it is fast, safe, and dependable. Using Linux commands in this lab showed me how cloud systems operate behind the scenes.

Clear documentation is important before building infrastructure because it helps engineers plan effectively. It makes sure everything is organized before implementation. Without proper notes, fixing errors and maintaining the system later would be hard. Good documentation also makes team communication much easier.

This lab helped me gain new skills in running Linux commands, checking system information, writing Markdown files, and learning about cloud providers. It also helped me explain technical ideas more simply.

Completing this mission improved my GitHub portfolio with organized files and clear examples of my work. It demonstrates my growing knowledge of cloud computing, which will help me in future projects and my career.
