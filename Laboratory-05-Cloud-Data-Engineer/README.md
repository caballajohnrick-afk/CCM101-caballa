# Laboratory 05: The Cloud Data Engineer

## Mission Overview
In this laboratory activity, an S3-compatible Object Storage server (MinIO) was deployed using Docker on a KillerCoda environment. The deployment demonstrates cloud-native storage patterns, port forwarding for service management, bucket creation, and uploading media files to emulate cloud backend infrastructure.

## Objectives
* Differentiate between Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server (MinIO) using Docker.
* Access a cloud service via a web interface using port forwarding.
* Create a storage bucket and upload objects (files) to the cloud.
* Document cloud storage operations using Markdown.

## Tools Used
* Docker
* MinIO Container Engine
* KillerCoda Ubuntu Environment
* Web Browser (Port Forwarding)
* Git & GitHub

## Skills Learned
* Containerizing stateful storage engines with custom runtime configurations.
* Mapping and exposing container networking ports for API and UI interactions.
* Managing S3-compatible bucket architectures and file upload operations.
* Authoring clear, technical cloud documentation in Markdown.
